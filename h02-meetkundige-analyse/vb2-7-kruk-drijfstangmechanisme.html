Bediening

Hoek van de kruk θ1
Standen uit het handboek:
L1 = 1 m, L2 = 3 m. In het handboek draait de kruk aan ω1 = 2π rad/s (één omwenteling per seconde); de animatie toont dat vertraagd, aan een kwart omwenteling per seconde.

Tonen

θ1 wordt gemeten vanaf de x-as tegen de wijzers in, θ2 is de hoek van de drijfstang met de horizontale, positief als A boven de geleiding ligt (zie de vector rB/A).

Baan van het midden C van de drijfstang

Uitdrukkingen uit het handboek

\kr{\vec r_{B/O}} = \kr{\vec r_{A/O}} + \kr{\vec r_{B/A}}
\phantom{\kr{\vec r_{B/O}}} = L_1\begin{Bmatrix}\cos\theta_1\\ \sin\theta_1\end{Bmatrix} + L_2\begin{Bmatrix}\cos\theta_2\\ -\sin\theta_2\end{Bmatrix}
\kr{\vec r_{B/O}} = \begin{Bmatrix}x_B\\ 0\end{Bmatrix}
\begin{aligned} L_1\cos\theta_1 + L_2\cos\theta_2 &= x_B\\ L_1\sin\theta_1 - L_2\sin\theta_2 &= 0 \end{aligned}
\theta_2 = \arcsin\left(\frac{L_1}{L_2}\sin\theta_1\right)
x_B = L_1\cos\theta_1 + \sqrt{L_2^2 - L_1^2\sin^2\theta_1}
\kr{\vec r_{C/O}} = \kr{\vec r_{A/O}} + \kr{\vec r_{C/A}}
\phantom{\kr{\vec r_{C/O}}} = L_1\begin{Bmatrix}\cos\theta_1\\ \sin\theta_1\end{Bmatrix} + \frac{L_2}{2}\begin{Bmatrix}\cos\theta_2\\ -\sin\theta_2\end{Bmatrix}
\phantom{\kr{\vec r_{C/O}}} = \begin{Bmatrix}L_1\cos\theta_1 + \frac{L_2}{2}\cos\theta_2\\ \frac{L_1}{2}\sin\theta_1\end{Bmatrix}

en na invullen van θ2:

\kr{\vec r_{C/O}} = \begin{Bmatrix}L_1\cos\theta_1 + \frac{L_2}{2}\cos\left(\arcsin\left(\frac{L_1}{L_2}\sin\theta_1\right)\right)\\ \frac{L_1}{2}\sin\theta_1\end{Bmatrix}

Het mechanisme heeft één kinematische vrijheidsgraad: θ1 legt de hele stand vast. Controle: C ligt steeds in het midden van A en B, dus rC/O = (rA/O + rB/O)/2.
